# ตัวอย่างสำนวน dragon — อ่านก่อนแปล/เกลาทุกครั้ง

คัดจากตอน 1-100 ซึ่งเป็นระดับสำนวนที่ต้องการ (audit 2026-10-11) สังเกตว่า**ไม่ได้แปลทีละคำ** แต่เติมน้ำเสียง จังหวะ และคำลงท้ายแบบไทย โดยไม่เติมเหตุการณ์ใหม่

## 🎯 โทนที่ต้องการ (ปิ๊กเลือก 2026-10-24: ผสม A + C)

สำรวจทั้งเรื่องแล้วโทนแบ่งเป็น 3 ยุค: A ตลกจัด (Ch 1-90), B กำลังภายในขำๆ (Ch 91-180), C วรรณกรรมนุ่มๆ (Ch 181-295)
ช่วงหลังศัพท์วรรณกรรมในบทบรรยายเพิ่มขึ้นราว 50% และอัศเจรีย์ลดลงครึ่งหนึ่ง มุกเลยแผ่วลง ให้ดึงพลังแบบ A กลับมา

- **ฉากตลก / ความคิดในหัวลีออน / แซวกัน → แบบ A:** ประโยคสั้น ห้าว ภาษาพูด มีอัศเจรีย์ได้ตามต้นฉบับ
  > (Ch 35) ลีออนยอมออกไปสู้รบกับยัยมังกรนี่สักสามร้อยกระบวนท่าในสนามรบอันนองเลือดยังจะดีเสียกว่าต้องมาทนรับการโจมตีทางจิตใจบนเตียงนอนแบบนี้ตลอดทั้งวัน! / บัดซบเอ๊ย!
  > (Ch 22) ถึงแม้โอกาสที่ข้าจะเป็นฝ่ายโดนนางจัดการจะมีสูงลิบลิ่วก็เถอะ แต่ช่างมันปะไร! สิ่งที่สำคัญที่สุดคือลูกสาวต้องมีความสุข!
- **ฉากบรรยาย / ดราม่า / ต่อสู้ → แบบ C:** สละสลวย อ่านลื่น แต่ไม่ซ้อนคำเกินต้นฉบับ (ดูกฎ "ปรับเป็นสำนวนไทยได้ แต่ห้ามเติมเนื้อหา")
  > (Ch 250) รอสวิธานั่งอยู่บนบัลลังก์สูง โน้มตัวมาข้างหน้าโดยใช้ข้อศอกยันโต๊ะไว้ เท้าคางด้วยมือข้างหนึ่ง นัยน์ตาสีเงินจับจ้องตามติดแผ่นหลังของลีออนไปไม่วางตา
- **ไม่ใช้ศัพท์โบราณแบบ B** (ไฉน / เล่า / ดั่ง / มิได้ / ประหนึ่ง / หาใช่) ในบทบรรยายหรือบทพูดของลีออน-รอสวิธา ยกเว้นตัวละครที่พูดโบราณจริงๆ (มังกรเฒ่า ราชามังกรโบราณ)
  > ❌ (Ch 95) ไฉนถึงชิงหลับไปดื้อๆ แบบนี้เล่า?! → ✅ จู่ๆ ก็หลับไปดื้อๆ แบบนี้เนี่ยนะ?!

## เช็กลิสต์ก่อนส่งแต่ละย่อหน้า
- บทบรรยายมีคำว่า "เธอ" หรือไม่ → เปลี่ยนเป็น นาง / แก / ชื่อ หรือละไป
- มี "ถูก…", "อย่างไรก็ตาม", "ในขณะเดียวกัน", "ได้รับการ" ที่ตัดได้ไหม
- ถ้าอ่านออกเสียงแล้วฟังเหมือนซับไตเติลแปลกูเกิล ให้เรียบเรียงใหม่
- ชื่อ ศัพท์ และคำเรียกพ่อ/แม่ ตรงกับ GLOSSARY ไหม
