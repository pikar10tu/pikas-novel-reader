# ตัวอย่างสำนวน revival-hunter — อ่านก่อนแปล/เกลาทุกครั้ง

ต้นแบบ = **ตอนที่ 1-3 ที่ Claude แปลนำร่อง (2026-10-24)** อ่านทั้ง 3 ตอนก่อนเริ่มทุก session ไม่ใช่แค่ไฟล์นี้
คู่มือแนว: `GENRE_modern-korean.md` · ศัพท์: `GLOSSARY.md`

## โทนของเรื่อง
- ตลกร้าย ภาษาปัจจุบัน คิมคงจาเล่าด้วย "ผม" แบบคนธรรมดาที่บ่นเก่ง สบถเก่ง ประชดตัวเองเก่ง
- คำสบถใส่ได้ตามต้นฉบับ (เหี้ย / ชิบหาย / เวร / วะ) แต่ **ไม่ใช้ กู/มึง** — ตอนกรีดร้องก็ยังเป็น "แล้วจะให้เอาสกิลนี้ไปใช้ยังไงวะ?!"
- ประโยคสั้นที่ต้นฉบับแยกบรรทัดเพื่อจังหวะตลก ให้คงสั้นแบบนั้น ห้ามรวมหรือขยาย

## สรรพนาม (ล็อกแล้ว)
| ใคร | ตัวอย่าง |
|---|---|
| คิมคงจา บรรยาย / คิด | "ผมอิจฉาเขา" / 'ผมก็อยากประสบความสำเร็จบ้าง!' |
| คิมคงจา → จักรพรรดิเพลิง (กลัว) | "ปะ- ปล่อยผมไปเถอะครับ! ได้โปรด!" |
| จักรพรรดิเพลิง | ฉัน / แก / "พี่ชาย" (ประชด): "พี่ชาย ทำฉันผิดหวังนะเนี่ย ทำเป็นไม่รู้เรื่องทำไม?" |
| จักรพรรดิเพลิง → นักบุญหญิง | ฉัน / เธอ: "ใครสั่งให้เธอมาฆ่าฉัน ตอบมาแค่นั้นพอ" |
| นักบุญหญิง | ดิฉัน / ค่ะ / ท่าน |
| บทบรรยายถึงผู้หญิง | "เธอ" ใช้ได้ (เรื่องนี้ไม่ห้าม) |

## รูปแบบเฉพาะ (ดูของจริงใน Ch 1-3)
- **บทสัมภาษณ์ในทีวี** ต้นฉบับไม่มีเครื่องหมายคำพูด → ไทยก็ไม่ใส่: `สวัสดีครับท่านจักรพรรดิเพลิง!`
- **บอร์ดเน็ต** คงบรรทัดเวลา/ปุ่มแยกย่อหน้า: `2 นาทีที่แล้ว | รายงาน` / `ตอบกลับ 5 ⏶` / `ㄴอยากเป็นเหมือนจักรพรรดิเพลิงจัง` / `1 วินาทีที่แล้ว | แก้ไข`
- **พาดหัวข่าว** `『...』` และจุดคั่น `ㆍ` คงไว้
- **ข้อความระบบ** ที่ไม่มีวงเล็บ (`Creating a skill card.`) แปลเป็นประโยคราชการสั้นๆ: `กำลังสร้างการ์ดสกิล` / ที่มีวงเล็บ: `[คุณตายแล้ว]`
- **การ์ดสกิล** คงลูกศร `→` และ `※`: `→แต่คุณตาย!`
- **มุกภาษา:** เล่นคำที่ใช้ไม่ได้ในภาษาไทย ให้หามุกไทยเทียบ เช่น คอมเมนต์สะกด "transloted" ผิด → ไทยใช้ "แปร" แทน "แปล"
  ส่วนมุก "โรคห่า/จักรพรรดิเพลิง" แปลตรงไม่ได้ ใส่ `(ผู้แปล: ...)` ครั้งแรกครั้งเดียว (Ch 1)
